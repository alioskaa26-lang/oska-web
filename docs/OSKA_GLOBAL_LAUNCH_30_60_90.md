# OSKA Global Launch — 30 / 60 / 90

## Before launch
Türkiye-first. TR + EN active. Keep AR/RU staged until navigation, forms, metadata and responsive QA are complete. Do not add manual hreflang that conflicts with Shopify localization. Validate schema, canonical behavior, image/video metadata, sitemap/robots readiness and owner-gated Search Console/GA4/Consent setup.

## First 30 days
Monitor index coverage, organic qualified entrances, RFQ funnel, sample requests, shortlist-to-RFQ conversion and top collection entrances. Publish only a small number of evidence-rich OSKA World articles. Build Google Images/Pinterest discovery from original product/workshop media. Fix field Core Web Vitals issues from real data.

## Days 31–60
Add market-specific pages only where buyer demand exists. Start digital PR/trade references around Istanbul manufacturing/private label. Compare buyer-type landing conversion and remove low-value pages rather than multiplying them.

## Days 61–90
Consider AR for Gulf demand and RU only after market/compliance decision. Expand editorial clusters from Search Console evidence. Add country pages only when each contains genuinely distinct buyer information.

## KPIs
Qualified RFQ rate, sample-request rate, shortlist-to-RFQ, catalogue requests, AI-to-human handoff, organic qualified entrances, image-search entrances and repeat/reorder requests.
