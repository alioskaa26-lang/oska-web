# OSKA Web Rules

- The site is a premium B2B catalogue/showcase; do not introduce retail checkout unless MASTER explicitly changes this.
- Navigation labels, product gender/category, destination page, and rendered content must match.
- A clickable item that opens unrelated content is a blocking QA failure.
- Preserve the approved premium editorial direction; do not make large visual rewrites outside task scope.
- Relevant UI changes must be checked on desktop, tablet, and mobile.
- Language behavior must preserve active TR + EN support and must not mix translations between routes.
- Hero/media changes must preserve approved dimensions, playback behavior, controls, and product identity.
- Before DONE: build/lint where relevant, then verify the changed route/component and every affected click path.
- Production publish remains Human Approval gated.
